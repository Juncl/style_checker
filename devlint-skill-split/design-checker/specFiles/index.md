# 规范清单

> 领域与规范库路径的映射表。用户未提供规范信息时，检查阶段按本清单向用户确认或让用户选择。

> 领域 key 必须与 `specFiles/` 下的子文件夹名一致；新增规范领域 = 建子文件夹 + 在此登记一行。
