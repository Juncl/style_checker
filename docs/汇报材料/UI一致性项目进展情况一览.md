# UI 一致性项目进展情况一览

## Q1（3 月）：技术穿刺，完成初始版本

- 打通开发侧ArkUI 节点与 设计稿节点的双侧解析，统一坐标与节点结构
- 实现初始版匹配算法 + 样式比对，检查项覆盖文本（字号、字重、颜色、字体）与非文本（圆角、填充、描边）
- 搭建前端一致性检查平台，端到端 MVP 跑通，可上传比对、查看差异报告

## Q2（4-6 月）：一致性能力完善

- 一致性平台对接内嵌到终端应用体验测试平台试用
- Web 侧支持：新增 Web 页面节点解析（DOM 树 + 计算样式），检查能力从鸿蒙应用扩展到 Web 页面
- 完善检查项：新增阴影、模糊、不透明度、间距等比对维度，扩展检查项覆盖面
- 算法进一步优化：持续迭代匹配与比对算法，降低误报漏报，提升检查准确率至80%
- AI 图图对比：新增基于视觉大模型的设计稿与实现截图像素级对比能力，补充参数比对覆盖不到的视觉差异


## Q3（7-9 月）：算法迭代优化 + skill/mcp 能力建设

1. 算法迭代优化
   1) 节点匹配升级：分块匹配改为可信文本锚点 + 相对位置拓扑 + 兜底匹配的多 Pass 算法，单点失败不再连坐整体
   2) 容器节点取值升级：同位置多层叠加节点智能合并（设计侧背景节点同化、开发侧 clip 圆角传播），消除取值失真类误报
   3) 整体准确率从 80% 提升至 86.5%
2.构建 UI 一致性 skill / mcp
